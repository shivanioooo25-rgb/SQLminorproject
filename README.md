
# SQL Injection Detection System in Web Requests Using Intelligent Filtering Mechanisms

## Project Overview
This project is a web-based security application that detects SQL Injection attacks in HTTP requests using Regular Expression (Regex) pattern matching. It analyzes user inputs, classifies attack severity, generates colored security alerts, logs detected attacks, and provides a monitoring dashboard.

## Features
- SQL Injection Detection
- Regex-Based Filtering
- Risk Level Classification
- Colored Security Alerts
- Attack Logging
- Attack Counter
- Monitoring Dashboard

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Regular Expressions (Regex)
